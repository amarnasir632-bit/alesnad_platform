# منصة الإسناد الأكاديمي

منصة تعليمية عربية تطورها وتشرف عليها شركة **AL WARITH**. تعرض الواجهة العربية من اليمين إلى اليسار، وتستهدف المنهج السوداني.

تشرح [وثيقة سياق المشروع](docs/PROJECT_CONTEXT.md) المتطلبات والأدوار وحالة التنفيذ. يشرح [دليل المساهمة](CONTRIBUTING.md) تقسيم العمل بين فريقي الواجهة والخلفية. وتوضح [خطة النشر](docs/DEPLOYMENT.md) المعمارية المتفق عليها وموانع الإطلاق وقائمة إعداد الاستضافة.

## التقنية

| الطبقة | التقنية | الاستخدام |
| --- | --- | --- |
| Frontend | HTML5 وCSS3 وJavaScript ES6+ | صفحات متجاوبة ودعم RTL |
| Backend | PHP 8.4+ | منطق الخادم والجلسات والتحقق والصلاحيات |
| Database | PostgreSQL | تخزين البيانات العلائقية |
| الاتصال | PDO مع `pdo_pgsql` | استعلامات محضرة واتصال PostgreSQL |
| كلمات المرور | `password_hash` و`password_verify` | تجزئة والتحقق من كلمات المرور |
| تبادل البيانات | JSON عند إضافة API | الطلبات والاستجابات البرمجية |

يستخدم التطبيق PHP دون إطار عمل حاليًا. يعتمد على HTML وCSS وJavaScript للواجهة وPHP/PDO للخادم. يشرح `database/migrations/` مخطط قاعدة البيانات القابل للتطبيق. لا تحفظ أي نسخة من قاعدة البيانات أو أسرار الاتصال في Git.

## المتطلبات

- PHP 8.4 أو أحدث.
- إضافتا PHP `pdo_pgsql` و`PDO`.
- PostgreSQL، وعميل `psql` لإعداد مستخدم وقاعدة محليين.
- Git.

## إعداد قاعدة البيانات والتشغيل محليًا

أنشئ مستخدم وقاعدة فارغين في PostgreSQL. من طرفية Fedora مثلًا:

```bash
sudo -u postgres psql
```

ثم داخل `psql`:

```sql
CREATE ROLE alesnad_app LOGIN;
\password alesnad_app
CREATE DATABASE alesnad_platform OWNER alesnad_app;
\q
```

سيطلب `\password` كلمة مرور المستخدم دون إدخالها في نص SQL. أنشئ ملف إعداد محليًا، واكتب كلمة المرور التي اخترتها فيه:

```bash
cp .env.example .env
```

عدّل `DB_PASSWORD` في `.env`. قبل التشغيل، عيّن قيم مهلة الجلسة وحدود محاولة الدخول التي يعتمدها مسؤول البيئة، وأنشئ سرًا بـ`openssl rand -hex 32` وضعه في `AUTH_THROTTLE_KEY`. تظل هذه القيم فارغة في المثال لعدم اعتمادها بعد، والتطبيق يتطلبها:

```text
SESSION_IDLE_TIMEOUT_SECONDS=
LOGIN_MAX_ATTEMPTS=
LOGIN_WINDOW_SECONDS=
LOGIN_LOCKOUT_SECONDS=
AUTH_THROTTLE_KEY=
```

ثم طبّق ترحيلات المخطط:

```bash
php database/migrate.php
```

قبل تشغيل الاختبارات، عيّن `QUIZ_MAX_ATTEMPTS`, و`QUIZ_INCOMPLETE_ATTEMPT_POLICY`, و`QUIZ_RESULT_VISIBILITY` في `.env`. عيّن أيضًا `QUIZ_DURATION_MINUTES` إذا لم يحدد الأستاذ مدة لكل اختبار. القيم تبقى فارغة في `.env.example` إلى أن يعتمد مالك المنصة السياسات؛ الخيارات المدعومة موضحة في `docs/API_CONTRACT.md`.

أنشئ حساب مدير النظام الأول من طرفية تفاعلية. لا يوجد حساب افتراضي أو كلمة مرور ثابتة:

```bash
php database/create_admin.php
```

شغّل خادم PHP المحلي:

```bash
php -S 127.0.0.1:8000 -t public public/router.php
```

افتح `http://127.0.0.1:8000`. لكل مطور قاعدة محلية مستقلة؛ يطبق الجميع ملفات الترحيل نفسها. لا ترفع `.env` أو النسخ الاحتياطية أو ملفات المحتوى الخاصة. تُحفظ ملفات المستخدمين خارج مجلد `public/`.

تحقق من الاتصال بقاعدة البيانات عبر `GET /health`. لإنشاء نسخة خاصة مسجلة ببصمة، شغّل `php database/backup.php`؛ راجع [إجراءات النسخ والاستعادة](docs/OPERATIONS_BACKUP_RESTORE.md) قبل الاستعادة، لأنها تستبدل بيانات قاعدة الهدف وتتطلب تأكيد اسمها.

## الوظائف الموجودة في المستودع

هذه القائمة تصف مكونات التطبيق. التشغيل يعتمد على إعداد البيئة، ونتائج الاختبارات مسجلة بصورة منفصلة في `docs/TRACEABILITY.md`؛ لا تعني القائمة وحدها اجتياز CI أو جاهزية النشر.

- اتصال PDO بإعدادات `.env`.
- ترحيل مخطط PostgreSQL وبذور الأدوار والصلاحيات.
- واجهة عربية RTL لعرض المواد الدراسية المدخلة في القاعدة.
- صفحة مدير لإضافة المراحل والصفوف والمواد يدويًا وربط المواد بالصف، محمية بصلاحية الخادم ومسجلة في سجل التدقيق.
- صفحة للمدير ومراجع المحتوى لمنح/سحب أهلية وصول الطالب يدويًا، مع سجل تاريخي وتدقيق، وحماية عرض الدروس المنشورة بناءً على قرار الوصول.
- دعوات حسابات الفريق بروابط لمرة واحدة صالحة 48 ساعة؛ المدير ومراجع المحتوى ينشئان حسابات الأستاذ والمراجع والمدير، ويحدد الموظف كلمة مروره بنفسه.
- إسناد المواد للأساتذة من صفحة الفريق؛ يقتصر إنشاء السؤال على الأستاذ المسند إليه أو المدير.
- بنك أسئلة أولي: الأستاذ المسند إليه ينشئ سؤالًا مصنفًا كمسودة أو يرسله للمراجعة، ويعدل المسودات أو الأسئلة المعادة؛ المدير أو المراجع يعتمد نشره. الاختبارات الإلكترونية لم تنفذ بعد.
- مكتبة أولية لرفع الكتب والامتحانات بصيغة PDF إلى تخزين خاص خارج `public/`، أو إضافة روابط HTTPS للموارد؛ يعتمد المدير أو المراجع المحتوى قبل ظهوره للطالب ذي صلاحية الوصول اليدوية. الملفات لا تقدم مباشرة من مسار عام.
- اختبارات إلكترونية أولية من الأسئلة المعتمدة للمادة، بمحاولات الطالب وحفظ الإجابات والتصحيح الآلي للأسئلة الموضوعية وتصحيح يدوي للمقال؛ الاختبارات غير محدودة المحاولات حاليًا وفق الإعداد الافتراضي، وتحتاج اعتماد سياسة المحاولات واختبار PostgreSQL.

## هيكل المستودع

```text
app/                    اتصال PDO والمصادقة وعروض PHP
database/migrations/    مخطط PostgreSQL وبذور الوصول
public/                 نقطة الدخول وأصول الواجهة العامة
storage/private/        مساحة محلية للملفات الخاصة، خارج web root
storage/backups/        مساحة محلية للنسخ الاحتياطية، غير متتبعة
docs/                   BRD وSRS وسياق المشروع
SqlDigram/              مخطط ERD المصدر والنسخ المصدرة
```

لا تضع أسرارًا في الشيفرة أو GitHub. عند النشر، استخدم HTTPS، واجعل `SESSION_SECURE=1`، واضبط مستخدم قاعدة البيانات بأقل صلاحيات لازمة، وأمّن `storage/` والنسخ الاحتياطية.
