## حدود التحقق

- تم فحص صياغة كل ملفات PHP باستخدام `php -l`.
- يغطي اختبار الوحدة تحليل نطاقات البايت الصحيحة ورفض النطاقات غير الصالحة.
- اختبارات PostgreSQL التكاملية لم تُنفذ في هذه البيئة لعدم توفر امتداد `pdo_pgsql` (ولا يستجيب خادم PostgreSQL المحلي). يلزم تشغيل واختبار الترحيل وسيناريوهات قاعدة البيانات في بيئة التطوير التي تتوفر فيها PostgreSQL.
- قائمة صيغ الملفات الحالية قيد اعتماد المالك/المشغل (OD-21)، وحد الرفع لا يعمل دون ضبط `UPLOAD_MAX_BYTES` (OD-14).
