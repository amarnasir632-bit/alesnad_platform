# تتبع المرحلة السابعة: التشغيل

| المتطلب | التنفيذ | التحقق |
| --- | --- | --- |
| NFR-007 النسخ الاحتياطي | `database/backup.php` يستخدم `pg_dump` بصيغة custom في `storage/backups/` مع صلاحيات خاصة وسجل `backup_records` يتضمن SHA-256 والحجم والحالة | `tests/static_phase7_checks.py`; يلزم تمرين فعلي على PostgreSQL قبل النشر |
| NFR-007 الاستعادة | `database/restore.php` يقبل سجلًا بحالة `VERIFIED` وبصمة مطابقة، ويتطلب تأكيد قاعدة الهدف ويستخدم استعادة ذرية | إجراء التمرين المعزول في `docs/OPERATIONS_BACKUP_RESTORE.md` |
| تجربة استعادة موثقة | توثيق إنشاء قاعدة مؤقتة وفحص الجداول وسجل النسخة ثم حذف القاعدة | يجب على مشغل البيئة تسجيل نتيجة تجربة فعلية؛ لا يدعي المستودع تنفيذها |
| NFR-009 سلامة الترحيلات | قفل PostgreSQL advisory lock، تخزين SHA-256، وإيقاف التطبيق عند اختلاف بصمة ترحيل مسجل | `tests/static_phase7_checks.py`; التحقق التنفيذي يتطلب PostgreSQL |
| NFR-011 فحص الصحة | `GET /health` يفحص اتصال DB ويرد بحالة عامة دون معلومات اتصال | `tests/static_phase7_checks.py` |
| سجلات أخطاء بلا أسرار | سجل منظم لاسم الحدث ونوع الاستثناء والرمز، دون رسالة الاستثناء أو SQL أو قيم الطلب | بحث ساكن عن مواضع `error_log` وفحوص المرحلة السابعة |

لا تعدل المرحلة أي ترحيل سابق. النسخ اليدوية لا تملك جدولة تلقائية أو تشفيرًا خاصًا داخل التطبيق؛ نقلها وتشفير وسيط التخزين وسياسة مدة الاحتفاظ مسؤوليات تشغيلية يجب اعتمادها لدى الجهة.

التكرار والاحتفاظ والتشفير وموقع النسخة الخارجية ومسؤول تجربة الاستعادة معلقة في `docs/OPEN_DECISIONS.md` (OD-24)، ولا يضع المشروع لها قيمًا افتراضية.
