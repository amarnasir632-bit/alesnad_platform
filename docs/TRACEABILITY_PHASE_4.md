## الاختبارات والقيود

- `php -l` على ملفات PHP، واختبار الوحدة لسياسات البيئة وقواعد خيارات الأسئلة.
- `python3 tests/static_phase4_checks.py` يتحقق من بقاء الترحيلات 001–006 والواجهة دون تعديل، ومسارات API وقيود الخادم.
- اختبارات PostgreSQL التكاملية وتطبيق الترحيل لم يتسنا في البيئة الحالية لعدم توفر `pdo_pgsql` وخادم PostgreSQL؛ يلزم تشغيلها محليًا على قاعدة اختبار مخصصة.
- لا قيم افتراضية لحد المحاولات أو المدة العامة أو سياسة النتيجة أو المحاولة غير المكتملة. توثيق القرارين المفتوحين OD-20 وOD-22 في `docs/OPEN_DECISIONS.md`.

## أثر الترحيل والتراجع

`007_quizzes_and_attempts.sql` يضيف مهلة محاولة، وحقول تصحيح وتعليق الأستاذ وتوقيته، وفهارس ومحفزات تفرض قواعد الخيارات وربط السؤال بالاختبار ومنع الإجابة خارج المحاولة النشطة. التراجع اليدوي في `database/rollback/007_quizzes_and_attempts.sql` يزيل هذه الحقول والقيود والمحركات، بما فيها بيانات التصحيح اليدوي والمهل التي أضيفت بعد الترحيل. أوقف التطبيق وخذ نسخة قبل التراجع، ولا تستخدمه في قاعدة مشتركة دون مراجعة البيانات.
